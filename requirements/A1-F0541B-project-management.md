# Project Management

**ID:** A1-F0541B  
**Status:** draft  
**Priority:** 1  

## Actors

- Project Managers
- Team Leads
- Executives/Stakeholders

## Overview

A system that allows project managers to define, organize, and monitor projects with start/end dates, milestones, budgets, and resource allocation while enabling multi-project tracking and portfolio management capabilities.

## Functional Requirements

1. Users can create projects with name, description, start date, end date, budget, and stakeholders
2. Users can assign team members to projects with roles and responsibilities
3. Users can define project milestones and track progress against planned timelines
4. Users can monitor project health through dashboard metrics and status indicators
5. Users can view project portfolios to understand organizational project distribution

## Non-Functional Requirements

1. System supports up to 100,000 concurrent users with 99.9% uptime SLA
